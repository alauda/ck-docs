# ClickHouseKeeperInstallations

`ClickHouseKeeperInstallation` (short name `chk`, API group `clickhouse-keeper.altinity.com/v1`) declares a ClickHouse Keeper quorum that the operator deploys and manages. A `ClickHouseInstallation` refers to it by name through `spec.configuration.zookeeper.keeper`. See [Deploy a Keeper quorum](../../../how_to/deploy_keeper_quorum.mdx).
